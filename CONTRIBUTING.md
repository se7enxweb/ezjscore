Contributing to ezjscore
========================

Thank you for helping. ezjscore is free software (GPL v2 or later) at
[github.com/se7enxweb/ezjscore](https://github.com/se7enxweb/ezjscore), and the
same code ships in the Exponential kernel.

- **Report a problem**: open an issue with your Exponential and PHP versions,
  the browser, what you did, what you expected, what happened, and the
  browser console's messages.
- **Send a change**: a pull request against `master`. Run `php -l` on changed
  PHP files and `node --check` on changed JavaScript. Check the pages that use
  what you changed with the browser's console open: no errors, and no jQuery
  Migrate warnings from your code.
- **Security problems**: please report them privately to info@se7enx.com rather
  than in a public issue.

Commit messages start with the kind of change, then say what it does:

```
Added: ...
Updated: ...
Fixed: ...
Removed: ...
```
